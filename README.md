# E. coli Nissle 1917 – sRNA under simulated microgravity

This repository tracks scripts, metadata, and analysis for studying small RNAs (sRNAs) in *Escherichia coli* Nissle 1917 under simulated microgravity (MG) versus normal gravity (NG).

## Dataset

- GEO: GSE147272 – Transcriptional profiling of probiotic *E. coli* Nissle 1917 under simulated microgravity.
- SRA runs used (from GEO/SRA Run Selector):

  - MG, exponential:  SRR11357510, SRR11357511
  - MG, stationary:   SRR11357512, SRR11357513
  - NG, exponential:  SRR11357514, SRR11357515
  - NG, stationary:   SRR11357516, SRR11357517

Raw FASTQ files are **not** tracked in this repository. Only metadata, scripts, and processed result tables are versioned.
