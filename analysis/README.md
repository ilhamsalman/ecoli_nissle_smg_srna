# analysis/

This directory contains curated downstream analysis outputs.

Tracked (kept in Git):
- inputs/ : processed inputs for DEG integration
- exp_phase/ : curated exponential-phase outputs
- stat_phase/ : curated stationary-phase outputs
- reference/ : reference annotation files used for coordinate-based analyses

Not tracked:
- _archive/ : old material
- intermediates_exp/ : intermediate files
- db/ : caches / auxiliary data
