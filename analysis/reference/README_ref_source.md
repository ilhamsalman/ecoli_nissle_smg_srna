# Reference files 

The `ref/` directory is intentionally excluded from version control because it contains large reference genomes and alignment indices.

Contents typically include:
- EcN_CP007799.1.fa (E. coli Nissle 1917 chromosome)
- EcN_ASM71459v1.fna (assembly FASTA)
- EcN_ASM71459v1.gff / .gtf
- Bowtie2 indices (*.bt2)
- GenBank file (*.gbk)
