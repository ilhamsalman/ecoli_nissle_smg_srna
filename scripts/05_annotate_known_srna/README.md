# Known sRNA Annotation

## Purpose
This module annotates ANNOgesic-predicted sRNAs by sequence similarity
against previously characterized bacterial sRNAs from the Bacterial
Small Regulatory RNA Database (BSRD), and identifies which known sRNAs
are present among candidate SMG-responsive sRNAs.

Outputs are written to:

results/sRNA_detection/05_known_srna/

---

## Inputs

Generated by previous pipeline steps:

### ANNOgesic outputs
- results/sRNA_detection/01_annogesic/srna_exponential.csv
- results/sRNA_detection/01_annogesic/srna_stationary.csv

### Genome reference
- ref/EcN_ASM71459v1.fna

### Candidate expression results
- results/sRNA_detection/04_srna_de_filtered/voom_exp_s2_candidates.csv
- results/sRNA_detection/04_srna_de_filtered/voom_sta_s2_candidates.csv

### External database (not provided in repo)
- ref/bsrd/BSRD.fa

NOTE:
Large FASTQ, BAM, and trimmed files are intentionally excluded
from version control and must be regenerated using the main pipeline.

## Required tools
- python

## One-time setup (BSRD database)

Create BLAST database:

```bash
makeblastdb -in ref/bsrd/BSRD.fa -dbtype nucl -out ref/bsrd/BSRD_sRNAs

---

## Workflow

Run scripts in order:

1) Convert ANNOgesic table → BED
   python scripts/05_annotate_known_srna/01_make_bed_from_annogesic.py <srna_table.tsv> <out.bed>

2) Extract strand-specific FASTA
   bash scripts/05_annotate_known_srna/02_extract_fasta.sh <genome.fa> <in.bed> <out.fa>

3) BLAST vs BSRD
   bash scripts/05_annotate_known_srna/03_blast_vs_bsrd.sh <query.fa> ref/bsrd/BSRD_sRNAs <out.tsv>

4) Filter Escherichia hits
   python scripts/05_annotate_known_srna/04_filter_annotate_escherichia.py <blast.tsv> ref/bsrd/BSRD.fa <out.csv>

5) Intersect known sRNAs with candidate sRNAs
   Rscript scripts/05_annotate_known_srna/05_intersect_known_srna.R

---

## Annotation thresholds

Identity ≥ 80%
Alignment length ≥ 50 nt
E-value ≤ 1e-5
Organism contains "Escherichia"
